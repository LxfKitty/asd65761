# CFnew v3.1.0 Fixed

这是 `LxfKitty/asd65761` 的 GitHub 直接覆盖版本。

仓库根目录保持原有部署结构：

- `m`：完整正式源码，供明文/主部署入口读取。
- `s`：完整稳定源码，与 `m` 字节一致，供稳定模式部署入口读取。
- `snippets`：紧凑版备用入口。

## v3.1.0 关键修复

- 恢复并保留原项目完整配置管理界面、地区配置、其它配置、高级配置、延迟测试、系统状态等原有模块。
- 修复 v3.0.0 中嵌入 HTML 模板后的浏览器 JavaScript 转义错误；该问题会导致页面脚本整体停止，所以会表现为“检测中… / 正在生成… / 原配置区没有显示”。
- `configCard` 改为默认可见：即使 KV/API 暂时失败，原配置区也不会被整个隐藏。
- “获取节点链接”真正调用 `/sub?target=link` 并验证 VLESS/Trojan/SS 链接，不再只是占位 UI。
- “自适应订阅”真正调用 `target=auto`，按客户端 User-Agent 选择订阅格式。
- “优选订阅生成”支持 `smart / random / custom`；在线优选会使用 `refresh=1` 强制刷新并验证节点。
- 自定义汇聚来源会写回原有 `yxURL` 配置，并继续走原项目的订阅生成逻辑。
- 修正 `/{UUID}/sub` 显式路由解析，使查询参数路径不再依赖宽松兜底分支。
- 保留 StableTransport：拨号超时、可选 A/AAAA 竞速、generation 防旧连接干扰、single-flight 重连、首字节 watchdog、fallback 健康/冷却、20KiB 上行聚合、队列双限额。
- 保留 BestCF v4.1：多源质量评分、历史稳定度、IPv4 网段分散、域名族去重、缓存与强制刷新。

## 上传方式

直接把本目录的文件覆盖到 GitHub 仓库根目录即可。此前自动部署器如果读取 `m` / `s`，不需要修改读取路径；版本号已高于 v3.0.0。

正式部署建议优先使用 `m` 或 `s`。两者内容完全一致。
